# מסנן תוכן — תוסף דפדפן לסינון תוכן לא צנוע

תוסף Chrome (Manifest V3) שמסתיר תמונות לא צנועות בזמן אמת בעזרת NSFWJS, ומסנן
עמודים לפי מילות מפתח בעברית ובאנגלית. **כל הבדיקות רצות מקומית במחשב** — שום
תמונה, כתובת או נתון גלישה לא נשלח לשרת חיצוני.

## התקנה והרצה

```bash
npm install
```

`npm install` מוריד אוטומטית את מודל NSFWJS (`mobilenet_v2_mid`, כ-4.3MB) אל
`public/models/`. אם ההורדה נכשלה, אפשר להריץ שוב:

```bash
npm run model
```

בנייה:

```bash
npm run build
```

טעינה בדפדפן:

1. `chrome://extensions`
2. להפעיל "מצב מפתח" (Developer mode)
3. "טעינת תוסף לא ארוז" (Load unpacked) → לבחור את תיקיית `dist`

## איך זה עובד

| רכיב | תפקיד |
|------|-------|
| `src/content/content.ts` | רץ בכל עמוד ופריים. מסתיר תמונות עד שהן נבדקות, שולח כל תמונה לבדיקה, מחליף תמונות חסומות בפלייסהולדר, וסורק את טקסט העמוד. |
| `src/background/service-worker.ts` | נתב. מוודא שמסמך ה-offscreen חי, מעביר אליו בקשות, ושומר מטמון תוצאות לפי כתובת. |
| `src/offscreen/offscreen.ts` | מסמך ה-offscreen — המקום היחיד בתוסף עם DOM ו-WebGL, ולכן כאן רץ המודל. |
| `src/popup/` | מתג הפעלה מהיר, מתג לאתר הנוכחי, ומונים. |
| `src/options/` | הגדרות מלאות: ספי חסימה, מילים נוספות, רשימות אתרים. |

זרימת בדיקת תמונה:

```
img נכנס לתצוגה → content.ts → service-worker (מטמון) → offscreen (NSFWJS)
                                                             ↓
                     פלייסהולדר אטום ← 'blocked' ← ציון משוקלל מול הסף
```

נחסמת שוב.

### סינון טקסט

נסרקים הכותרת, הכתובת, תגיות ה-meta ותוכן העמוד מול רשימה מובנית (עברית
ואנגלית) בתוספת מילים אישיות. ברירת המחדל: **ארבעה ביטויים שונים** חוסמים את
העמוד כולו. הרשימה בעברית מתחשבת בתחיליות (ב, ה, ו, ל, מ, ש, כ), ובאנגלית נדרש
גבול מילה מלא — כדי לא לחסום עמודי חדשות, רפואה או לימוד בטעות.

בנוסף יש רשימת דומיינים מובנית שנחסמת מיד, עוד לפני שהעמוד נטען.

## החלטות תכנון

**למה offscreen ולא בתוך סקריפט התוכן?** service worker ב-MV3 לא יכול להריץ
WebGL. טעינת המודל בכל לשונית בנפרד הייתה מבזבזת מאות מגה-בייט. מסמך ה-offscreen
טוען את המודל פעם אחת לכל הדפדפן.

**למה התמונה נמשכת שוב ב-offscreen ולא נשלחת מהעמוד?** קנבס שצויירה לתוכו תמונה
ממקור אחר הוא "tainted" ולא ניתן לקרוא ממנו פיקסלים. ה-offscreen פועל בהרשאות
התוסף ולכן יכול למשוך את התמונה ישירות. המחיר: תמונות שדורשות עוגייה או Referer
עשויות להיכשל — יש הגדרה "חסימה כשהבדיקה נכשלה" למי שמעדיף להחמיר.

**למה מייבאים מ-`nsfwjs/core`?** נקודת הכניסה הראשית של nsfwjs גוררת שלושה
מודלים ארוזים בתוך החבילה, כ-35MB. `core` מקבל כתובת מודל משלנו ומדלג עליהם —
הבנייה ירדה מ-35MB ל-1.9MB.

## מגבלות ידועות

- **וידאו לא נסרק.** רק תמונות ותמונות רקע ב-CSS. דגימת פריימים אפשרית להוספה.
- **תמונות ב-`blob:`** שנוצרו בעמוד עצמו אינן נגישות לתוסף ולא נבדקות.
- **הבדיקה עולה זמן.** התמונה הראשונה בכל לשונית ממתינה לטעינת המודל (~1.5 שניות
  פעם אחת לכל הדפדפן), ואחריה כ-100ms לתמונה.
- **המודל אינו מושלם.** יש שגיאות לשני הכיוונים; רמת ההקפדה ניתנת לכוונון
  בהגדרות.
- **זה אינו כלי אכיפה.** משתמש שיודע להיכנס ל-`chrome://extensions` יכול לכבות
  את התוסף. זהו כלי עזר למי שרוצה בו, לא מנעול.
